Review Intelligence — classification and enforcement triage over 7M reviews

An end-to-end pipeline over the Yelp Open Dataset — 6,990,280 reviews across 150,346 businesses and 1,987,897 users. Spark ingestion, a multi-label content classifier, and an unsupervised reviewer-anomaly ranker that produces candidates for a human enforcement queue. Served through ONNX Runtime behind a documented API.

The dataset carries no ground-truth labels for fraudulent reviews, so the scope was split by what the data honestly supports: supervised classification against labels that exist, and unsupervised ranking that feeds human adjudication rather than pretending to be a classifier.
